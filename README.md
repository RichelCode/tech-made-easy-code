# Tech Made Easy: the code 💕

Hi, I'm Richel. I write **Tech Made Easy** on Medium: beginner-friendly machine learning stories in plain words, with no heavy math.

This repo holds the code from those stories, so you can run it yourself, poke at it and learn by doing. Every folder matches one story.

- **Nothing to download.** Every dataset is either made by the code or ships inside scikit-learn.
- **Small and readable.** One script per story, about 100 lines, with comments that follow the story step by step.
- **Checked.** Each folder's README shows the exact output you should see, so you know it worked.

## How to use this repo

**1. Get the code.** Pick one:
- **No Git?** Click the green **Code** button at the top of this page, then **Download ZIP**, and unzip it.
- **Have Git?** Run `git clone https://github.com/RichelCode/tech-made-easy-code.git`

**2. Open a project folder.** For example, `01-time-series-forecasting`.

**3. Follow that folder's README.** It's always the same four lines:

```bash
python3 -m venv .venv
source .venv/bin/activate        # On Windows: .venv\Scripts\activate
pip install -r requirements.txt
python forecast.py               # each folder's README names its script
```

Never used a terminal or a virtual environment before? The **[Getting Started guide](GETTING_STARTED.md)** explains every step, with fixes for the most common errors.

## How to get the most out of it

1. **Read the story first.** The code makes much more sense once you know the idea behind it.
2. **Run the code without changing anything.** Check that your output matches the README.
3. **Then break it on purpose.** Change one number, run it again and see what moves. That's how the ideas really stick.
